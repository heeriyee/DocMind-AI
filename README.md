# DocMind AI

DocMind AI is an AI-powered document assistant that allows users to upload documents and interact with them through an intelligent chat interface.

## Features

- Document upload
- AI-powered document chat
- Document-based question answering
- Interactive chat interface
- Context-aware responses
- Modern web interface

## Tech Stack

### Frontend
- React
- TypeScript
- CSS
- Vite

### Backend
- Python
- Flask

### AI / Document Processing
- ChromaDB
- Google Gemini API
